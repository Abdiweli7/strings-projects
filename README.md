# Character Finder

This is a JavaScript project that finds the first, last and middle character of a word.

# Features
- Finds first character
- Finds last character
- finds middle character
- Prevents empty input
- Displays results dynamically

# Technologies Used
- HTML
- CSS
- JavaScript

# Concepts Practiced
- DOM Manipulation
- Functions
- Event Listeners
- String Methods
- Conditions

# String Methods Used
- charAt()
- trim()
- length
